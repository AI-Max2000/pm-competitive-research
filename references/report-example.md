# 报告与示例

## 可裁剪报告结构

1. 本次决策与主要结论，标注证据限制。
2. 研究范围、竞争集合与时间口径。
3. 与决策相关的能力/价格对比。
4. 关键竞品优势、限制和用户反馈。
5. 差异化机会、反证、可行性与验证动作。
6. 来源记录与待核实项。

若只研究一个定价问题，直接回答价格口径和结论，不扩展成完整市场报告。面向管理层突出取舍与行动；面向产品团队保留流程和能力边界。

## 合成材料示例

输入材料：A 的官网写明年付每席位折算每月 20 元；B 的资料只写“联系销售”；A 的帮助文档支持 CSV 导出，B 暂无导出资料。

正确比较：A 有公开年付折算价，是否可月付、最低席位和税费仍需核对；B 价格未知。无法判断 A 比 B 便宜。A 官方说明支持 CSV 导出；B 导出能力未知，不能写“不支持”。

可形成的行动：根据实际席位与用量获取 B 的可比报价；核对双方导出是否满足用户所需字段，再讨论迁移成本。以上为演示材料，不代表真实产品价格或已完成研究。

质量自查：把任一竞品换成自己的产品，证据标准是否仍公平；删掉品牌名后，对比是否仍能解释真实取舍。
